Настройка среды разработки и создание приложения «Бюджет поездки»
Цель работы
Научиться запускать PHP-проект на локальном сервере, обрабатывать данные с помощью условий и циклов, создавать массивы и функции, разделять программу на файлы.

Задание
Разработайте страницу, которая показывает расходы на поездку и рассчитывает:

общую стоимость;
сумму на одного участника;
остаток бюджета или сумму превышения;
самый большой расход.
Данные задаются непосредственно в коде. Формы и база данных в этой работе не используются.

1. Установка и проверка среды
Установите среду для запуска PHP и редактор кода. Можно использовать Laragon, XAMPP или совместимую среду для вашей операционной системы.

После установки:

Запустите веб-сервер.
Создайте папку lab1_familiya в каталоге проектов.
Откройте её в редакторе.
Создайте файл index.php.
Проверьте выполнение PHP:

<?php

echo "<h1>Мой первый PHP-проект</h1>";
echo "<p>Автор: Иван Иванов</p>";
echo "<p>Группа: ...</p>";
echo "<p>Версия PHP: " . PHP_VERSION . "</p>";
Укажите свои данные и откройте страницу через HTTP, например:

http://localhost/lab1_familiya/index.php
Для Laragon папка проекта обычно размещается внутри www, для XAMPP — внутри htdocs. Адрес зависит от настройки среды.

Проверка: измените текст в файле, сохраните его и обновите страницу. Затем просмотрите исходный код страницы в браузере и сравните его с PHP-файлом.

2. Информация о поездке
Выберите направление поездки. Определите переменные для названия поездки, количества участников и общего бюджета группы.

$napravlenie = "Поездка в Орхей";
$uchastniki = 4;
$byudzhet = 6000;

const VALYUTA = "MDL";
Создайте полноценный HTML-документ с кодировкой UTF-8. В начале страницы выведите название поездки, автора, количество участников и бюджет.

Пример вывода переменной в HTML:

<h1><?= $napravlenie ?></h1>
<p>Количество участников: <?= $uchastniki ?></p>
Все суммы в работе относятся ко всей группе и ко всей поездке.

3. Массив расходов
Создайте многомерный массив минимум из пяти расходов. Для каждого укажите название, категорию и сумму.

$rashody = [
    [
        "nazvanie" => "Аренда транспорта",
        "kategoriya" => "Транспорт",
        "summa" => 1200
    ],
    [
        "nazvanie" => "Проживание",
        "kategoriya" => "Жильё",
        "summa" => 2400
    ]

    // Добавьте остальные расходы.
];
Для первого запуска используйте следующие данные:

Расход	Категория	Сумма, MDL
Аренда транспорта	Транспорт	1200
Проживание	Жильё	2400
Продукты	Питание	1000
Входные билеты	Развлечения	500
Прочие расходы	Прочее	300
После проверки замените название поездки и расходы собственными данными.

4. Вывод расходов
Используя foreach, сформируйте HTML-таблицу:

№ | Название расхода | Категория | Сумма

Пример формирования части строки:

<?php foreach ($rashody as $rashod): ?>
    <tr>
        <td><?= $rashod["nazvanie"] ?></td>
        <td><?= $rashod["kategoriya"] ?></td>
        <td><?= $rashod["summa"] ?> MDL</td>
    </tr>
<?php endforeach; ?>
Самостоятельно добавьте заголовки таблицы и порядковые номера строк. Валюту выводите из константы VALYUTA.

Под таблицей покажите количество расходов, используя count().

5. Вычисления и условия
Общая стоимость
Сложите суммы всех расходов. Используйте аккумулятор, который инициализируется перед циклом.

Пример принципа суммирования:

$total = 0;

foreach ($rashody as $rashod) {
    $total += $rashod["summa"];
}
Стоимость на одного участника
Разделите общую стоимость на количество участников:

Стоимость на человека = общая стоимость / количество участников
Если количество участников меньше или равно нулю, выведите сообщение «Некорректное количество участников» и не выполняйте деление.

Проверка бюджета
С помощью if, elseif и else определите результат:

Условие	Что вывести
Расходы меньше бюджета	«Бюджета достаточно» и оставшуюся сумму
Расходы равны бюджету	«Бюджет использован полностью»
Расходы больше бюджета	«Бюджет превышен» и сумму превышения
Для исходного примера ожидается:

Количество расходов: 5
Общая стоимость: 5400 MDL
Стоимость на человека: 1350 MDL
Бюджета достаточно. Осталось: 600 MDL
6. Дополнительная обработка массива
Выполните две операции.

Найдите самый большой расход. Выведите его название и сумму. Для исходных данных это:

Самый большой расход: Проживание — 2400 MDL
Выведите отдельно расходы от 1000 MDL включительно. Используйте цикл и условие. Если подходящих записей нет, покажите соответствующее сообщение.

Результаты должны вычисляться из массива, а не записываться вручную.

7. Создание функций
После проверки вычислений перенесите их в функции:

function obshchayaSumma(array $rashody): float
Возвращает сумму расходов. Для пустого массива — 0.

function summaNaCheloveka(float $total, int $uchastniki): float
Возвращает стоимость на одного участника. Вызывается после проверки положительного количества участников.

function statusByudzheta(float $byudzhet, float $total): string
Возвращает сообщение о состоянии бюджета с оставшейся суммой или суммой превышения.

Пример использования функции:

$total = obshchayaSumma($rashody);

echo "Общая стоимость: " . $total . " " . VALYUTA;
Функции возвращают результаты через return. Вывод выполняется в HTML-странице.

8. Разделение на файлы
Организуйте проект следующим образом:

Файл	Содержание
data.php	Информация о поездке, константа и массив расходов
functions.php	Определения функций
index.php	Подключение файлов, вызовы функций и HTML
В начале index.php подключите файлы:

require __DIR__ . "/data.php";
require_once __DIR__ . "/functions.php";
После разделения результат страницы должен остаться прежним.

9. Проверка и сдача
Проверьте приложение при следующих условиях:

Проверка	Ожидаемое поведение
Бюджет больше расходов	Вывод остатка
Бюджет равен расходам	Сообщение о полном использовании
Бюджет меньше расходов	Вывод суммы превышения
Участников 0	Сообщение без деления на ноль
Нет расходов от 1000 MDL	Сообщение об отсутствии таких записей
Массив расходов пустой	Общая сумма 0, сообщение об отсутствии расходов
Сдать: архив проекта и краткий отчёт с названием установленной среды, версией PHP, скриншотом страницы и результатами проверок.
