## Реализация
- Расходы хранятся в многомерном массиве: у каждого расхода есть название, категория и сумма.
- Таблица расходов строится циклом `foreach`, номер строки — счётчиком, количество расходов — через `count()`.
- `obshchayaSumma()` — суммирует расходы через аккумулятор, для пустого массива возвращает 0.
- `summaNaCheloveka()` — делит общую сумму на число участников. Вызывается только если участников больше нуля, иначе выводится «Некорректное количество участников».
- `statusByudzheta()` — через `if / elseif / else` возвращает остаток, сообщение о полном использовании или сумму превышения.
- `samyyBolshoyRashod()` — находит самый большой расход циклом.
- `krupnyeRashody()` — отбирает расходы от 1000 MDL включительно.
- Все результаты вычисляются из массива, а не записаны вручную.

## Проверки
| Проверка | Что изменено в `data.php` | Ожидаемое поведение | Результат |
|----------|---------------------------|---------------------|-----------|
| Бюджет больше расходов | без изменений (бюджет 7000) | Вывод остатка | «Бюджета достаточно. Осталось: 150 MDL» |
| Бюджет равен расходам | `$byudzhet = 6850` | Сообщение о полном использовании | «Бюджет использован полностью» |
| Бюджет меньше расходов | `$byudzhet = 6000` | Вывод суммы превышения | «Бюджет превышен на 850 MDL» |
| Участников 0 | `$uchastniki = 0` | Сообщение без деления на ноль | «Некорректное количество участников» |
| Нет расходов от 1000 MDL | суммы 1800, 2500, 1100 заменены на 400 | Сообщение об отсутствии таких записей | «Расходов от 1000 MDL нет.» |
| Массив расходов пустой | `$rashody = []` | Общая сумма 0, сообщение об отсутствии расходов | «Расходов нет.», «Общая стоимость: 0 MDL» |
